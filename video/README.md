# Course video

Final deliverable:

- `final/battery_dt_course_project_1080p.mp4` — 10 min 55 s, 1920×1080, H.264/AAC
- `final/battery_dt_course_project.srt` — burned-in English captions are also supplied as SRT
- `final/thumbnail.png`, `final/chapters.txt`, `final/video_meta.json`
- `script.md` — full English narration with timecodes and chapter table

Narration is synthetic (`en-US-AndrewNeural`, rate +3%) over slides and a live
dashboard recording. There is no human face. The dashboard footage is a real
recording of the Streamlit service receiving MQTT traffic; the mouse cursor and
click ripples are composited for legibility. The recording uses a fresh stack
at 20× simulation speed, waits for the initial transient to leave the chart,
applies an 18 A load, injects a cooling failure, reduces the load to 5 A after
the alarm, runs a what-if scenario, inspects SQLite, and finally kills the
simulator to show the retained LWT offline/stale state.

## Rebuild

Optional dependencies (kept out of the runtime `requirements.txt`):

```bash
.venv/bin/pip install -r video/requirements-video.txt
# Playwright's Chromium is available in the user cache; or run:
.venv/bin/playwright install chromium
# ffmpeg must be installed on PATH.
```

Build order from the project root:

```bash
.venv/bin/python video/build_slides.py
.venv/bin/python video/tts.py
.venv/bin/python video/record_demo.py
.venv/bin/python video/assemble.py
.venv/bin/python video/build_script.py
```

`record_demo.py` starts the complete stack itself with `--fresh --speed 20` and
requires ports 1883 and 8501 to be free. It takes roughly four minutes including
the warm-up. `tts.py` needs network access to the Edge speech endpoint; change
`VOICE`/`RATE` at the top of that file to use a different voice, or replace the
mp3 files and rerun `assemble.py`.

Intermediate files `frames_demo/` (≈244 MB), `segments/` (≈61 MB) and the
recording log are intentionally excluded from the submission archive. They can
be regenerated by the commands above. The final MP4, slides, narration audio,
slide sources, SRT, and build scripts are included.
